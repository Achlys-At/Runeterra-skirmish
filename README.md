# 🎮 Runeterra Chronicles

Un **jeu tactique au tour par tour** dans l'univers de League of Legends !

## 📖 Description

**Runeterra Chronicles** est un jeu développé en **HTML/CSS/JavaScript** permettant au joueur de combattre des ennemis avec des champions de League of Legends. Le jeu propose un système de combat au tour par tour stratégique avec:

- 🎯 **Système de combat tactique** : Placez vos champions, lancez des attaques spéciales
- 🔮 **Champions variés** : Chacun avec leurs propres compétences et statistiques
- ⚔️ **Ennemis progressifs** : Difficulté croissante au fil des missions
- 🎨 **Interface immersive** : Design inspiré de l'univers Runeterra
- 💜 **Multiple game modes** : Mode histoire et autres défis

## 🎨 Univers

Inspiré par **League of Legends** et l'univers de **Runeterra**, le jeu te place dans des batailles épiques contre des créatures et champions ennemis.

## 🛠️ Technologies

- **HTML5** - Structure du jeu
- **CSS3** - Design et animations
- **JavaScript Vanilla** - Logique du jeu (sans frameworks externes)

## 🚀 Comment jouer

### 1️⃣ Ouvrir le jeu
Simplement double-clique sur `index.html` ou ouvre-le dans un navigateur web

### 2️⃣ Jouer
- Sélectionne tes champions
- Lance des attaques contre les ennemis
- Gagne les batailles pour progresser
